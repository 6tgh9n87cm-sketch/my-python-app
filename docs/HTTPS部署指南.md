# HTTPS 部署指南（让麦克风/语音对话可用）

> 目标：给你的 AI 智能体 NOVA 套上 HTTPS，这样浏览器才允许使用麦克风做语音对话。
> 方案：买一个自己的域名（约 ¥10–30/年）→ 解析到服务器 → 服务器跑一键脚本装 nginx + 免费证书。

---

## 第 1 步：买一个域名

1. 打开腾讯云域名注册：https://dnspod.cloud.tencent.com/domain/register
2. 搜一个想要的英文/拼音名字，后缀选便宜的，比如 `.top` `.xyz` `.cn`（首年常 ¥10 左右）。
   - 例：`nova-ai.top`、`keke-nova.xyz`
3. 加入购物车 → 实名认证（按提示上传身份证）→ 支付。
4. 买好后，在 **域名注册 → 我的域名** 里能看到它。

## 第 2 步：把域名指向你的服务器

1. 进入域名的 **解析 / DNS 解析** 页面（腾讯云叫 DNSPod）。
2. 添加两条 **A 记录**：
   - 主机记录 `@`  → 记录值 `124.220.216.238`
   - 主机记录 `www` → 记录值 `124.220.216.238`
3. 保存。解析生效通常几分钟到几小时（一般很快）。

## 第 3 步：开放 80 和 443 端口

1. 腾讯云控制台 → **轻量应用服务器**（或云服务器）→ 你的实例 → **防火墙 / 安全组**。
2. 添加规则：
   - 应用类型选 `HTTP`(80) 和 `HTTPS`(443)，或手动添加 TCP 80、TCP 443，来源 `0.0.0.0/0`。
3. 保存。

> 之前的 8000 端口可以保留（不影响），也可以顺手关掉，让外界只能走 443。

## 第 4 步：在服务器上跑一键脚本

用 OrcaTerm（或 SSH）登录服务器，切到 root（`sudo su`），执行：

```bash
cd /var/www/app
# 先把脚本下载/同步到服务器（它已随代码部署在 scripts/ 目录）
bash scripts/setup-https.sh 你的域名
```

把 `你的域名` 换成你买的，比如：

```bash
bash scripts/setup-https.sh nova-ai.top
```

脚本会自动：
- 安装 nginx + certbot
- 把 gunicorn 收口到本机（只让 nginx 访问）
- 申请 **免费** Let's Encrypt 证书并开启 HTTPS
- 配置证书 **自动续期**（90 天，免维护）

## 第 5 步：验证

浏览器打开 **https://你的域名**，看到 NOVA 界面即成功。点麦克风按钮，浏览器会请求麦克风权限 → 允许 → 直接跟 NOVA 语音对话。

---

## 常见问题

- **证书申请失败 / 超时**：多半是域名没解析好或 80 端口没开。等几分钟再跑一次脚本里的 certbot 命令即可。
- **麦克风还是不能用**：确认地址栏是 `https://` 开头（不是 `http://` 或 IP），且已点「允许」麦克风权限。
- **想换域名**：再跑一次 `setup-https.sh 新域名` 即可，旧证书不影响。
