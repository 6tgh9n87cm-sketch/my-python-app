# 零基础：从购买服务器到自动部署 · 完整教程

> 本文假设你完全没接触过服务器、GitHub、SSH 等概念。
> 每个步骤都写清了「在哪个软件里操作」「点哪个按钮」「输入什么内容」。

---

## 第一步：买一台云服务器（5 分钟，约 ¥50/月）

### 开哪个网站

- **腾讯云**（推荐，访问比较快）：<https://cloud.tencent.com>
- **阿里云**（备选）：<https://www.aliyun.com>

有手机号就能注册。

### 买哪种

搜「**轻量应用服务器**」或「**云服务器 ECS**」，选最便宜的就行，Python 项目不需要高配置。

**关键参数（照这个选）：**

| 参数 | 选什么 |
|------|--------|
| 地域 | 离你近的（比如「广州」「上海」） |
| 镜像（系统） | **Ubuntu 22.04 LTS** |
| CPU / 内存 | 1 核 1G 或 2 核 2G 就够了 |
| 带宽 | 最低档 3Mbps |
| 时长 | 先买 1 个月试试 |

> 注意：操作系统必须选 **Ubuntu 22.04**（Linux），不要选 Windows Server。后面所有教程基于 Ubuntu。

### 买完后你会拿到什么

- **公网 IP**：一串数字，比如 `123.45.6.78`（记下来，后面天天用）
- **root 密码**：初始密码（首次登录后会让你改，记住新密码）

## 第二步：在本地生成 SSH 密钥（1 分钟）

SSH 密钥就像一把数字钥匙：本地留一把私密钥匙（自己保管），服务器放一把公开锁（公钥），GitHub Actions 用私密钥匙就能无人看守登录你的服务器。

### 打开终端（你的 Windows 电脑上）

**你刚刚已经装了 Git 的话**：右键桌面空白处 → 选「**Git Bash Here**」，弹出一个黑窗口。

**如果没装 Git**：先下载 <https://git-scm.com/download/win>，一路「Next」安装，然后再试上面步骤。

### 在黑窗口里输入这条命令（复制粘贴，回车）

```bash
ssh-keygen -t ed25519 -f deploy_key -N ""
```

窗口不会有什么特别反应，但你的桌面上（或当前文件夹里）会多出两个文件：

- `deploy_key` → **私密钥匙**（绝对不要发给任何人，后面要贴到 GitHub）
- `deploy_key.pub` → **公开锁**（可以给别人，后面要放到服务器上）

## 第三步：从你电脑连接到服务器（首次）

你的云服务器在机房里，你需要通过 SSH 远程登录，就像远程遥控一台电脑一样。

### 3.1 下载连接工具（二选一）

**推荐：WindTerm**（免费，中文界面）
- 下载地址：<https://github.com/kingToolbox/WindTerm/releases>
- 下载 `WindTerm_2.6.1_Windows_Portable_x86_64.zip`
- 解压后双击 `WindTerm.exe` 打开

**备选：FinalShell**（也是中文，免费）
- 下载地址：<https://www.hostbuf.com/t/988.html>

### 3.2 用 WindTerm 连接服务器

1. 打开 WindTerm → 点击左上角「**会话**」→「**新建会话**」
2. 填：
   - **主机**：你服务器的公网 IP（比如 `123.45.6.78`）
   - **端口**：`22`
   - **用户名**：`root`
   - **密码**：你买服务器时设的密码
3. 点「**连接**」，第一次会弹窗问「接受主机密钥」，选接受。

连接成功后你会看到一个黑底白字的命令行界面，光标闪烁——这就是服务器的「终端」，和你电脑上的 Git Bash 一样用法。

## 第四步：把初始化脚本传到服务器上并运行

### 4.1 把 `scripts/server-init.sh` 传到服务器

**方法**：在 WindTerm 里，直接**拖拽文件**到窗口里。

1. 打开你电脑上的文件夹 `C:\Users\29984\WorkBuddy\2026-07-30-22-50-26\scripts\`
2. 把 `server-init.sh` 文件从文件夹**拖到** WindTerm 窗口里，松手。
3. 文件就传到服务器当前目录了。

### 4.2 把公钥也传上去并运行脚本

在 WindTerm 的命令行里输入（一行一行输，每行回车）：

```bash
# 第 1 行：确认文件在
ls server-init.sh

# 第 2 行：先手动把你的公钥内容粘进去（看下面的操作）
nano deploy_key.pub
```

执行 `nano deploy_key.pub` 后，会用文本编辑器打开一个空文件。

**同时**，在你电脑上用记事本打开 `deploy_key.pub`（右键 → 打开方式 → 记事本），`Ctrl+A` 全选，`Ctrl+C` 复制。

回到 WindTerm，`Ctrl+V` 粘贴，然后按 `Ctrl+X`，再按 `Y`，再按 `Enter`，保存退出。

```bash
# 第 3 行：运行初始化脚本，把公钥写入 deploy 账号
sudo bash server-init.sh "$(cat deploy_key.pub)"

# 第 4 行：确认服务文件已创建
ls /etc/systemd/system/myapp.service
```

看到「✅ 初始化完成」就说明服务器准备好了。

## 第五步：建 GitHub 仓库并配置 Secrets（网页操作）

### 5.1 注册 / 登录 GitHub

打开 <https://github.com>，注册一个账号（用邮箱即可）。

### 5.2 新建仓库

1. 登录后，点右上角「**+**」→「**New repository**」
2. 填：
   - **Repository name**：`my-python-app`（随便命名）
   - **Description**：可留空
   - **Public** 或 **Private** 随便选
   - **不要**勾选「Add a README file」（我们已经有了）
3. 点「**Create repository**」

### 5.3 页面跳转后，复制仓库地址

你会看到类似：
```
https://github.com/你的用户名/my-python-app.git
```
复制这行文字。

### 5.4 配 Secrets

进入仓库页面 → 顶部标签点「**Settings**」→ 左侧菜单点「**Secrets and variables**」→「**Actions**」→ 绿色按钮「**New repository secret**」

依次添加以下 4 个：

| Name | Value（填什么） |
|------|----------------|
| `SSH_HOST` | 你服务器的公网 IP（比如 `123.45.6.78`） |
| `SSH_PORT` | `22` |
| `SSH_USERNAME` | `deploy` |
| `SSH_KEY` | 用记事本打开 `deploy_key` 文件，`Ctrl+A` 全选 → `Ctrl+C` 复制 → 粘进去 |

⚠️ `SSH_KEY` 粘贴后应该以 `-----BEGIN OPENSSH PRIVATE KEY-----` 开头，以 `-----END OPENSSH PRIVATE KEY-----` 结尾。确保完整粘贴。

## 第六步：推送代码到 GitHub

回到你电脑上的 **Git Bash**（第二步里打开的黑窗口），输入以下命令（一次一行，回车）：

```bash
# 进入项目目录
cd /c/Users/29984/WorkBuddy/2026-07-30-22-50-26/

# 关联你刚建的 GitHub 仓库（把下面这行里的 URL 换成你刚才复制的那个！）
git remote add origin https://github.com/你的用户名/仓库名.git

# 推送代码
git push -u origin main
```

推送过程中可能会弹出 GitHub 登录窗口，用你刚注册的 GitHub 账号登录即可。

## 第七步：看自动部署是否成功

### 7.1 在 GitHub 网页上看

打开你的仓库页面 → 点顶部「**Actions**」标签 → 你会看到一条正在运行的流水线（叫 "CI/CD Pipeline"）→ 点进去可以看每个步骤的实时日志。

成功时三个步骤都是绿色 ✅：
- `Lint & Test`（代码检查 + 测试）
- `Build distribution`（打包）
- `Deploy to server`（部署到服务器）

### 7.2 在服务器上确认

回到 WindTerm，输入：

```bash
sudo systemctl status myapp
```

如果看到 `active (running)` 就说明服务已经跑起来了！

### 7.3 在浏览器里访问

打开浏览器，输入：
```
http://你的服务器IP:8000
```

能看到你的应用就成功了。

## 常见问题

**Q: 买完服务器找不到 IP？**
A: 腾讯云/阿里云的控制台首页 → 云服务器列表，IP 地址直接显示在列表里。

**Q: 连不上服务器？**
A: 确认 IP 没写错；确认服务器状态是「运行中」；检查服务器控制台里「安全组」或「防火墙」是否放行了 22 端口。

**Q: git push 报 Permission denied？**
A: 说明 GitHub 要登录，窗口里会让你输入用户名和密码（现在 GitHub 用 token，网页上 Settings → Developer settings → Personal access tokens 创建一个）。

**Q: 部署时 Deploy 步骤报错？**
A: 最常见原因是 Secrets 没配对。去检查 `SSH_KEY` 是不是完整粘贴、`SSH_HOST` IP 是否正确。
